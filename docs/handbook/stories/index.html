    Story pages

    Each page says what a user can now do, shows the flow, lists the API operations, says how to try it (Bruno requests, seed.sh, tunnels.sh) and links the verdict and evidence. The step-by-step kit stays in the acceptance guide.

    • S3: A tenant user signs in and is scoped to their tenant only
