        Vision

        What the product is

        The platform (nava-core) is a multi-tenant ticketing platform. Many customer organisations, called tenants, share one installation, one database and one set of services. The main risk of that design is one tenant seeing or changing another tenant's data, so the architecture is built around keeping tenants apart. ADR-001 records the ground rules; see goals and non-goals.

        Who uses it

        • Tenant users and applications call the REST API at /api/v1 with a token issued by the identity provider.
        • Tenant administrators publish entity types, set access rules and manage users and groups through the platform API.
        • Platform operators onboard tenants, run migrations and administer the Temporal workflow engine.
        • Engineers and the product owner build and accept the platform; this handbook is for them.
