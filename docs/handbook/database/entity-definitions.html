                    Entity definitions

                    An entity type (entity_definitions) is a per-tenant row, not a table, so a tenant defines its own types with no DDL. Its JSON Schema lives in entity_definition_versions, one immutable row per published version. Publishing inserts a version and moves entity_definitions.current_version. A version is never updated, so a record written under version 3 can always be read against version 3.

                    key and number_prefix are set once. numbering_mode (gaps or gapless, ADR-005) decides how the type's record numbers are allocated (see numbering). Onboarding seeds a provisioning tenant's default types under pinned policies. Both tables are audited.
