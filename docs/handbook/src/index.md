Orientation for engineers: what the platform is, how it is built, and where each part lives. Every page describes only what is on `main`; anything on a story branch is marked "in progress".

The sidebar runs in reading order: **Start here** (what the product is and its goals), **Concepts** (tenants, users and groups, entity types, records, access rules, workflows, audit, record numbers), **How it works** (system map, write pipeline, workflows, security, invariants), **Reference** (database, decisions, stories, benchmarks, glossary) and **Operations** (local stack, observability, troubleshooting). A product tour will sit between Start here and Concepts. Use the search box for a name you already know.
