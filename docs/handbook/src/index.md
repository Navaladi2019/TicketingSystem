Orientation for engineers: what the platform is, how it is built, and where each part lives. Every page describes only what is on `main`; anything on a story branch is marked "in progress".

Start with [Vision](vision/index.md) for the goals and the nine invariants, then [System](system/index.md) and [Architecture decisions](adr/index.md) for how the core is built and why. [Stories](stories/index.md) lists what has been delivered, and [Workflows](workflows/index.md), [Database](database/index.md) and [Security](security/index.md) go deeper on each layer. [Benchmarks](benchmarks/index.md), [Operations](operations/index.md) and the [Glossary](glossary/index.md) are for reference.

Reading order: Vision, System, Architecture decisions, then the section for the layer you work on. Use the search box for a name you already know.
