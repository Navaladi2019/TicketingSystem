*Summary. The normative text is the linked `.md`.*

## Problem

ADR-010 and RFC-022 say a PUT with a stale expected version gets 409. The route returns `412 version_conflict` with the current `ETag`, as every `If-Match` route does, and its tests and Bruno `S10-14` assert 412. The 409 came from reading the Go error name `ConflictError` as a status code.

## Decision

| # | One line |
|---|---|
| E2-1 | A stale `If-Match` is `412 version_conflict` with the current `ETag`; nothing is written. No code change. |
| E2-2 | Two PUTs with the same `If-Match` write once: the second gets 412 (sequential or concurrent, via the entity-type lock), or the replayed 200 when it reuses the first one's `Idempotency-Key` and body. A reused key with another body is `409 idempotency_key_reuse`, and a duplicate with the same key while the first is still running is `409 idempotency_in_flight`; those are the route's only 409s. |
| E2-3 | RFC-022 is not edited; this erratum is the correction. |

## Residuals

None.
