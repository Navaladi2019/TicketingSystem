An **ADR** records one decision and is normative. An **amendment** (`A<n>`) changes a rule of its parent ADR; an **erratum** (`E<n>`) corrects or clarifies one. Each page here summarises its record and links the normative text, which always wins. Pages marked `in-progress` describe work that is not yet on `main`.
