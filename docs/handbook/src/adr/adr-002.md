## Problem

*Paraphrases: "1. Decision", "8. Options considered and rejected".* The story-5 acceptance step "Alice's `/me` shows group service-desk" could not be shown: a person could not read their own group memberships without running SQL.

## Decision

*Paraphrases: "1. Decision", "2. Contract", "3. Design".*

- `GET /api/v1/me` gains `group_paths`, an always-present array of `{id, path}`. The existing `groups` array is unchanged.
- It lists only the caller's own groups, in the caller's own tenant, checked in SQL under row-level security.
- The Keycloak adapter's `/t/<tenant_id>` prefix is stripped, so the adapter's layout is not part of the additive-only v1 contract.
- Paths are for display only. No authorization decision, ACL, cache key or metric may key on a path.
- This is a new contract field and read port, so it is its own ADR rather than an amendment of [ADR-001](adr-001.md). No invariant changes.

How "display only" is enforced (section 5): a test pins the fields of the authorization principal; type-qualified lint rules allow one caller of the path reader; a later ACL-epic acceptance criterion requires the ACL compiler to use group ids only.

## Options that lost

*Paraphrases: "8. Options considered and rejected".* Amending the story instead; a `group_paths` string array parallel to `groups` (aligned only by position); last-segment names (ambiguous); keeping the tenant prefix; putting paths in the principal; a path reader fed from a caller-supplied id list (would let a member list any group); a 500 when the prefix is missing; a `GET /groups/{id}` endpoint.

## Consequences

*Paraphrases: "4. Acceptance criteria", "6. CTO sign-off on protected paths", "10. Invariant check".* One short extra transaction on `/me` only. Isolation tests gain a tenant-B marker group and an exact-membership-set check. A path without the expected prefix is dropped and logged (never logging the path).

## Accepted risks

*Paraphrases: "7. What is being accepted".*

| # | Risk | Why accepted |
|---|---|---|
| R-a | A tenant admin can name a subgroup so its stripped path looks like another tenant's. | It affects only that tenant's own members. |
| R-b | Any handler in one file may call the path reader. | Lint exclusions are per file. **Closed by [ADR-002-E1](adr-002-e1.md).** |
| R-c | The "starts with /" and "never null" rules are not enforced at runtime. | Unit tests cover the cases that matter. |
| R-d | Membership is read in a second transaction, so `group_paths` can lag `groups` by one request. | Display data may lag. |
