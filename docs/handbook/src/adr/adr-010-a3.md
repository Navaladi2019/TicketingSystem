## Problem

A2's region shapes start from the units of the caller's subtree S. That works when the units hold many records of the listed type. A *concentrated* type has few records under S, yet the query still visits every unit, at 3.4 to 5.9 µs per unit. TICK-1037 failed this row at 9,099 units with 161.57 ms. This is residual A2-R6.

## Decision

| # | One line |
|---|---|
| A3-1 | Shape R: `(r.org_unit_id IN (SELECT descendant_id FROM org_unit_closure …)) IS TRUE`. It is a hashed closure set, probed once per record of the type. It is used for the page and the count, with no `IS NOT NULL` conjunct. |
| A3-2 | The order is:<br/>1. A2-5a.<br/>2. A missing N̂_e is never R.<br/>3. N̂_e > α·U_cert skips the closure count.<br/>4. Otherwise a folded probe counts closure rows up to U_hash. R is chosen iff ⌈N̂_e/α⌉ ≤ n < U_hash; otherwise P3 decides as in A2. |
| A3-3 | The constants are α = 3.3 (measured), U_cert = 10,111 (equal to the groupsync alert) and U_hash = 20,222. They are computed, never configured. |
| A3-4 | R computes the same predicate as every shape, so rows and the capped count never change. |
| A3-5 | R reads at most about 33,400 records, plus a hash of fewer than 20,222 units. It never runs without its hashed set. |
| A3-6 | The selector cannot see m. That costs +6.3 ms for a type entirely under S, which is accepted. |
| A3-7 | The security requirements carry over from A2-6. AR-TICK-1040-01 gains two in-tenant timing bits. |
| A3-8 | `authz_under_list_shape_total` gains `shape="records"`. |
| A3-9 | TICK-1037 reruns with `bench_conc` at 9,099 and 10,111 units, and with ticket at root within 1 ms of the control. |

## Evidence

From SP-1f (TICK-1092), on paired wall-clock with the floor gate passed:
- **`bench_conc` at 9,099 units:** R scores 67.66 / 64.40 ms p95, against 79.58 / 99.26 ms for the A2 control in the same window.
- **At 10,111 units:** R scores 36.43 / 75.85 ms.
- **Correctness:** 0 row mismatches against the control.

## Residuals

- **A3-R1:** α was measured on one type size.
- **A3-R2:** the R count's index choice. The plan test decides it.
- **A3-R3:** m is invisible to the selector.
- **A3-R4:** the planner may misjudge the hash below U_hash. A plan test at 20,222 guards it.
- **A3-R5:** a stale-low N̂_e.
- **A2-R4, extended:** R assumes custom plans.
- **`AR-TICK-1040-01`, extended:** see [accepted risks](../security/accepted-risks.md).
