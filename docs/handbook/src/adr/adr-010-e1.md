## Problem

CI-6 required `ReadBranches` on a converted format-1 policy to give the same branch count and the same SQL text as `main`. In PR #765 the branch count matched in 48 of 48 golden cases, but text and bind arguments differed in 8, in two semantically equal ways.

## Decision

| # | One line |
|---|---|
| E1-1 | Rewrite (a) is allowed: a constant `true` conjunct is folded away. Same plan in 8 of 8 measurements. |
| E1-2 | Rewrite (b) is allowed: `caller: self` in a `where` renders `= $n::uuid` with a `uuid.UUID` argument, not `= ANY($n::uuid[])` with a one-element `[]string`. It **can change index choice**; measured neutral or faster on two 800k-record data shapes. |
| E1-3 | The golden test normalizes exactly (a) and (b), and (b) only for the caller's own id. It never skips a case. Lands in PR #765 before it merges. |
| E1-4 | No change to the planner or the converter. Option B (make the text identical) is rejected. |

[E3](adr-010-e3.md) adds a third allowed rewrite, (c): a one-group `caller: my_groups` renders `= $n::uuid`.

## Residuals

`AR-TICK-993-01` in [accepted risks](../security/accepted-risks.md): rewrite (b) on an unmeasured data distribution could slow a list. Latency only; access decisions are unchanged.
