## 2026-11-15: TICK-961, Go 1.27 upgrade ships the toolchain, UUIDv7 ids and strict JSON decode; the stdlib `uuid` move is cut to its own story

- **Decided by:** the Technical Lead, on TICK-961. Story branch: `TICK-961/go-1-27-upgrade`.
- **Decision 1:** the story is four tasks: TICK-962 (toolchain 1.27.4 + `go fix`, `core-dev`), then TICK-963 (UUIDv7 for every persisted id + guard, `backend-dev`) and TICK-964 (`encoding/json/v2` strict decode at request boundaries, `core-dev`) in parallel, then TICK-965 (handbook, Technical Lead). Critical path: TICK-962 → TICK-964.
- **Decision 2 (drift found):** v4 primary keys are minted in more places than the story listed. Besides `internal/entitytypes/entitytypes.go:212,372` and `internal/groupsync/apply.go:230,344,454`, also `internal/workflowdefs/workflowdefs.go:201,248` (definition and version ids), `internal/workflow/def/ids.go:30` (step ids stored in the immutable version row) and `internal/workerguard/child.go:34` (child workflow id, inside `workflow.SideEffect`, so v7 is replay-safe). All go to v7 in TICK-963. Existing stored v4 ids stay; nothing is rewritten.
- **The cut:** replacing `github.com/google/uuid` with the stdlib `uuid` package (340 files) leaves this story. It touches files that every open story (S18, S21, S28, the ADR-010 work) also changes, which breaks story independence, and it delivers no invariant: `google/uuid` `NewV7` already gives us v7. It becomes its own backlog story. **Trigger:** no open story branch changes Go files under `internal/` or `cmd/`, or `google/uuid` is deprecated or stops building. It also needs the D-P6 rule "gofrs/uuid → google/uuid" and its depguard entry updated in the same change.
- **Integration risk:** TICK-964 changes request decode sites that S18 (TICK-669) and the ADR-010 data-filter work also touch. The Technical Lead re-checks overlap before releasing TICK-964 and holds it if a decode site is in an open story's diff.
- **Invariants:** golden hash tests (`content_sha256`, `diff_sha256`, export v1, idempotency request hash) must pass unchanged in every task; a changed golden file stops the task and comes back to TICK-961.
- **Dissent:** none.
