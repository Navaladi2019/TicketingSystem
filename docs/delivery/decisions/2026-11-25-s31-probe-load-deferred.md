## 2026-11-25: S31, the probe load of one list is deferred with a trigger (`AR-S31-05`)

- **Decided by:** the Technical Lead, on finding 3 (Low, not blocking) of the Security & Multi-Tenancy Reviewer's whole-story review of PR #867 (TICK-946 comment 01a210af, 2026-11-25). Story S31 (TICK-946).
- **Finding:** one list can run up to 16 probes (`authz.ReadBranchThreshold`), each reading up to 20,001 records (`KStarMax` + 1), one after the other, on the database all tenants share. The record limit does not bound the cost: when the type has few records under U, a probe looks up every live unit under U, about 10 µs per unit, and the tree has no size cap (ADR-010-A2 A2-7, A2-R6). One probe took 24.30 ms p95 at 9,099 units with 0 records under U (TICK-1037 run 2, `bench_conc`). Security corrected this on TICK-1117.
- **Decision:** ship S31 without a bound on the units visited; nothing is built now. The R1 bench passed at the certified tree (70.08 / 82.69 ms p95 against 150 ms, TICK-1037), but it has no row for a plan with 16 region branches: 16 such probes would take roughly 320 ms at the median (inferred, not run), over the 150 ms list budget.
- **Owner:** the Technical Lead.
- **Trigger to revisit:** `authz_under_probe_seconds` p95 above 25 ms for 15 minutes, or a slow-list report from a tenant whose policies use more than 4 `under` branches. No alert watches the first one: read it in Prometheus with `histogram_quantile(0.95, sum by (le) (rate(authz_under_probe_seconds_bucket[15m])))`.
- **Limits of the first trigger:** it is the p95 of single probes over all tenants, with no tenant label, so one tenant's slow probes can hide among the others', and a list of 16 probes of 24 ms each stays below it. Only the slow-list report covers those. 25 ms is also about what the certified bench measured (24.30 and 23.16 ms p95 on the scored rows, 26.88 ms with `state=new`), so the trigger firing at the certified tree is not a regression by itself.
- **Options when it fires:** a lower cap on region leaves per plan, or one probe for all leaves. Both need the Solution Architect.
- **Dissent:** none.
