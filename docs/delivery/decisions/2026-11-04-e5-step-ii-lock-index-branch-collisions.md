## 2026-11-04: E5 step (ii) lands with an ACCESS EXCLUSIVE lock and no RESTRICT index; task PRs on a story branch must be green against its head
- **Decided by:** the Technical Lead on TICK-538 (P5-E5-5, PR #448), after the Security & Multi-Tenancy Reviewer approved it and the Quality, Testing & CI Advisor reported CI. No dissent recorded.
- **Decision 1 (erratum candidate for ADR-004-E5 D10):** the ADR says step (ii-a) takes SHARE ROW EXCLUSIVE. In practice `DROP CONSTRAINT` takes ACCESS EXCLUSIVE on `records` and `groups` until commit. Measured on PostgreSQL 16.10 with 50,000 groups and 1,000,000 records, the hold is 13.9 ms. `lock_timeout` (5 s) bounds it, and a test shows a timed-out run changes nothing (CI-E5-8). The migration stays as written. The ADR text is corrected the next time ADR-004-E5 is amended (owner: the Solution Architect). Logged as AR-TICK-538-02.
- **Decision 2 (deferred):** there is no index for the `records_assignment_group_fkey` RESTRICT check. After step (ii), only the owner can delete a group, so no tenant or runtime role can start the scan of `records` (99 ms at 1M rows, growing linearly). **Trigger:** the design of any job that purges or erases groups adds `records (tenant_id, assignment_group_id)` in the same change. Logged as AR-TICK-538-01.
- **Decision 3 (process):** PR #443 (TICK-541) and PR #445 (TICK-436) each merged green into `TICK-419/one-audit-log`, but they broke each other (`TestAuditDiffReadOnlyInReader`). That turned the story branch red for every task PR after them. From now on, a task PR merges only when its GitHub Actions run is green against the **current** head of the story branch. If the story branch moved after the run, the merger merges the story branch into the PR branch and waits for a new green run. The fix for this collision is finding 0 of TICK-552.
- **Follow-ups:** TICK-560 replaces the single-sample ratio in `TestP511CommitCheckLinearity` with a median of three runs, because it fails at random on shared runners. TICK-561 adds the cross-tenant RESTRICT regression test the security review suggested.
