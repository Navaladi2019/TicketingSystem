## 2026-10-28: shared tables are append-safe: story-prefixed ids, `merge=union`, one file per decision
- **Decided by:** the Technical Lead on TICK-288 (D6); implemented in TICK-295.
- **Decision:**
  - New `todo.md` and `accepted-risks.md` rows use `TODO-<story>-NN` and `AR-<story>-NN`; work outside a story uses the task id. Existing ids stay.
  - `.gitattributes` sets `text eol=lf merge=union` on `docs/delivery/todo.md`, `docs/security/accepted-risks.md`, `docs/pins.md` and `.gitignore` (`docs/**` is `-text`, which would otherwise make git treat them as binary). `tools/ci/uniontest` merges two branches that each append a row.
  - New decisions are files under `docs/delivery/decisions/`; the index in `decision-log.md` is generated by `go run ./tools/docindex` and `task lint` fails when it is stale. Older entries stay in `decision-log.md`.
- **Dissent:** none.
