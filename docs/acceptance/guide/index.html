TicketingSystem acceptance guide: stories S1–S8

Everything delivered on main in stories S1 to S8, tried by hand on your own machine. Each use case has a flowchart, the exact clicks, what you should see and what a failure looks like. The Bruno collection walks the same steps with automatic checks, and adds a test suite for every API operation.

Download the kit (.zip)Download as one HTML file

The zip holds this site, the Bruno collection (with its local environment) and the helper scripts. Unzip it anywhere: the pages work offline from a double-click. The scripts run from the repository checkout, at docs/acceptance/guide/tools/.

Start here

  1. Prerequisites: clone, start the stack, seed the two tenants, open the tunnels, open the collection in Bruno.
  2. Pick a use case below, or run the whole collection: in Bruno's Runner, or headless with sh docs/acceptance/guide/tools/api-test.sh (about 3 minutes with the 15-second group sync, plus up to 5 minutes for the last folder).
  3. Something red? Troubleshooting.
