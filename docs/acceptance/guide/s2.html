A query without the right tenant returns nothing

Story S2, TICK-44. Kit: docs/acceptance/s2-tenant-isolation.md.

What you can test

Tenant isolation is enforced by PostgreSQL row-level security: a query with no tenant, an empty tenant or another tenant gets 0 rows. Over HTTP, the only tenant data route on main is GET /api/v1/me, so the collection shows that naming another tenant in a header, the query or the body never changes which tenant answers.

BEGIN; SELECT set_config('app.tenant_id', '00000000-0000-4000-8000-0000000000a1', true);
